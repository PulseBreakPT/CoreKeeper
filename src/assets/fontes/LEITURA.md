# Tipos de letra

| Ficheiro | Família | Licença |
| --- | --- | --- |
| `baloo2-latin.woff2`, `baloo2-latin-ext.woff2` | Baloo 2 (variável, 400–800) | SIL Open Font License 1.1 |
| `nunito-latin.woff2`, `nunito-latin-ext.woff2` | Nunito (variável, 400–900) | SIL Open Font License 1.1 |
| `space-grotesk.woff2` | Space Grotesk | SIL Open Font License 1.1 |
| `cinzel-600.woff2` | Cinzel | SIL Open Font License 1.1 |
| `spectral-*.woff2` | Spectral | SIL Open Font License 1.1 |

Todas são livres e podem ser redistribuídas com a aplicação. Baloo 2 e Nunito servem o
launcher Nexus Word (`src/palavras/menu-referencia.css`); os subconjuntos são os `latin`
e `latin-ext` do Google Fonts, suficientes para o português.
